# 주간 리포트 작성 기준

친구들 board 문서(`board/<uid>`)의 `log`·`dsum`으로 지난주(일~토) 리포트를 만든다.

## 반드시 넣을 것
- 전체/개인 볼륨, 운동일, 세트·횟수, 부위별 세트(주 10~20세트 기준), 추정 1RM(Epley), 재미 어워드, 다음 주 처방
- **🍺 음주**: 술 기록(`n`이 소주·맥주·막걸리·와인, `dr:1`, `s: [[도수, 병]]`)
  - 사람별 주간 병 수, 순수 알코올(g) = 용량(ml) × 도수/100 × 0.789
    - 용량: 소주 360 · 맥주 500 · 막걸리 750 · 와인 750
  - 소주 환산 병 수(알코올 g ÷ 46.9), 깎인 볼륨(알코올 1g당 −30kg)
- **🩺 건강 정보**
  - WHO·보건복지부 저위험 음주 기준과 비교(남성 하루 40g 이하, 주 2회 이상 금주일)
  - 술 마신 다음 날 운동 볼륨 변화(음주 다음 날 vs 평소)
  - 음주가 근성장·회복에 주는 영향(단백질 합성 저하, 수면 질 저하, 탈수)
- HTML 한 파일(외부 링크 없음)로도 뽑아서 카톡으로 보낼 수 있게
