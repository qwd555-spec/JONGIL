# 💪 볼류머

친구들과 함께 볼륨을 쌓고 겨루는 헬스 기록 앱

날짜별로 운동을 기록하고 **일간 / 주간 / 월간 총볼륨**을 계산하는 웹앱입니다.
설치나 서버 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있어요.

## 기능
- **운동 목록 + 검색**: 가슴/등/어깨/하체/이두/삼두/전완/복근/전신/유산소 약 240개 운동 내장 (`exercises.js`)
  - 한글, 초성(`ㅂㅊ`), 영문(`squat`), 줄임말(`사레레`, `OHP`, `RDL`) 검색, 띄어쓰기 무시
  - 부위별 / 최근 / 내 운동 필터, 검색 결과를 누르면 바로 오늘 기록에 추가
  - 목록에 없으면 "직접 추가"
- **일간**: 날짜 선택 → 운동 추가 → 세트별 무게·횟수 입력, 운동별/하루 총볼륨 자동 계산
  - 같은 운동을 추가하면 지난번 세트(무게·횟수)를 자동으로 불러옴
  - 세트 추가 시 직전 세트 값 복사
- **주간** (월요일 시작): 주간 총볼륨, 요일별 막대 그래프, 부위별·운동별 볼륨, 지난주 대비 증감률
- **월간**: 월간 총볼륨, 볼륨 히트맵 달력, 주차별 볼륨, 부위별·운동별 볼륨, 지난달 대비 증감률
- **휴식 타이머**: "✓ 기록하고 휴식 시작!" 버튼 → 기록 저장 + 화면 가운데 팝업으로 원형 타이머 표시(기본 60초, ±10초 조절). 끝나면 진동 + 알림음 + 팝업 강조 (진동은 안드로이드 지원, 아이폰은 소리로 알림)
- **맨몸 운동 볼륨**: 일간 화면에서 몸무게 입력 → 푸시업·풀업·딥스 등은 (몸무게 + 추가 중량) × 횟수, 어시스트 머신은 (몸무게 − 보조 중량) × 횟수. 직접 추가한 운동도 "맨몸 운동?" 칩으로 설정 가능
- **그룹 순위 + 응원 댓글** (Claude 공유 링크에서): 닉네임으로 참가, 이번 주/이번 달/전체 총볼륨·운동일수·운동별 최고 중량 순위, 친구에게 댓글과 이모지 응원. 공유되는 건 날짜별 총볼륨과 최고 중량뿐
- **기준은 근력 볼륨**: 총볼륨·달력·순위는 근력 운동만 합산
- **유산소 볼륨 (별도 집계)**: 러닝·풋살 등은 거리(km)·시간(분)을 기록하면 소모 칼로리 × 25 로 환산 (근력운동 1시간 ≈ 1만kg ≈ 350kcal 기준). 거리 기반은 몸무게 × km × 계수, 시간 기반은 (MET − 1) × 몸무게 × 시간
- **설정**: JSON 백업/복원, CSV 내보내기(엑셀용), 전체 삭제

## 디자인
소프트 그레이 레이어 + 블랙 포인트의 모바일 우선 UI, 하단 플로팅 탭바, 라인 아이콘(SVG), Pretendard 폰트.

## 볼륨 계산
볼륨 = 무게(kg) × 횟수, 모든 세트 합산

## 데이터 저장
브라우저 `localStorage`에 저장됩니다. 기기/브라우저를 바꾸기 전에 설정 탭에서 백업하세요.

## 배포 (GitHub Pages)
저장소 Settings → Pages → 브랜치 선택 후 저장하면 `https://<아이디>.github.io/<저장소>/` 로 접속 가능합니다.
