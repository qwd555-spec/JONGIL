# 💪 헬스 볼륨 기록

날짜별로 운동을 기록하고 **일간 / 주간 / 월간 총볼륨**을 계산하는 웹앱입니다.
설치나 서버 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있어요.

## 기능
- **일간**: 날짜 선택 → 운동 추가 → 세트별 무게·횟수 입력, 운동별/하루 총볼륨 자동 계산
  - 같은 운동을 추가하면 지난번 세트(무게·횟수)를 자동으로 불러옴
  - 세트 추가 시 직전 세트 값 복사
- **주간** (월요일 시작): 주간 총볼륨, 요일별 막대 그래프, 운동별 볼륨, 지난주 대비 증감률
- **월간**: 월간 총볼륨, 볼륨 히트맵 달력, 주차별 볼륨, 운동별 볼륨, 지난달 대비 증감률
- **휴식 타이머**: "✓ 기록하고 휴식 시작!" 버튼 → 기록 저장 + 휴식 카운트다운(기본 60초, 설정에서 변경). 끝나면 진동 + 알림음 + 화면 깜빡임 (진동은 안드로이드 지원, 아이폰은 소리로 알림)
- **설정**: JSON 백업/복원, CSV 내보내기(엑셀용), 전체 삭제

## 볼륨 계산
볼륨 = 무게(kg) × 횟수, 모든 세트 합산

## 데이터 저장
브라우저 `localStorage`에 저장됩니다. 기기/브라우저를 바꾸기 전에 설정 탭에서 백업하세요.

## 배포 (GitHub Pages)
저장소 Settings → Pages → 브랜치 선택 후 저장하면 `https://<아이디>.github.io/<저장소>/` 로 접속 가능합니다.
